# Тестовое задание: «Тестирование сервиса обработки кредитных заявок»

## Бизнес-требования

**Маргарита Меркулова**  
*Product Owner*

Добро пожаловать в команду инновационного кредитования МТС Банка!

Наша команда разрабатывает новый сервис, отвечающий за обработку кредитных заявок.

Сейчас мы разрабатываем мобильное приложение, которое должно отображать с бэкенда актуальные тарифы и условия.

Чтобы повысить конверсию, мы сразу же даём возможность клиентам отправить заявку, нажав на кнопку возле тарифа.

После отправки заявки клиенту должна отображаться:

- информация о статусе этой заявки;
- кнопка **«Удалить»**.

Для начала мы будем использовать рандом, чтобы одобрять или отклонять заявки.

Тебе, как нашему новому QA-инженеру, предстоит протестировать этот сервис. Технические подробности тебе расскажет твой технический лидер — Андрей.

## Техническое задание

**Андрей Сурков**  
*Руководитель практики тестирования*

В этом задании тебе необходимо развернуть реализованный разработчиками проект **«Оформление кредита»**.

Описание методов сервиса ты можешь найти в документации.

Опиши в md файле тест-кейсы с понятным названием, шагами и ожидаемым результатом.

Далее в папке `Test` покрой автотестами методы сервиса.

Для этого:

1. Опиши методы отправки запросов.
2. Реализуй проверки ответов.
3. Используй библиотеки:
   - **Rest Assured**;
   - **JUnit 5**;
   - **Allure**.
4. Добавь случайно сгенерированные данные. Для этого можно использовать библиотеку **Datafaker**.
5. Обязательно напиши хотя бы **один параметризованный тест**.

Полученный проект можно использовать как часть своего портфолио.

Если в процессе возникнут трудности или сложности — пиши в чат, наш коллектив тебе обязательно поможет.

## Локальный запуск проекта

Проект можно развернуть локально.

### Требования

Для локального запуска необходимо установить:

- Java последней версии;
- Maven;
- PostgreSQL.

### Настройка PostgreSQL

В PostgreSQL необходимо создать пользователя:

- **Логин:** `user`
- **Пароль:** `1234`

Для этого пользователя необходимо создать базу данных:

- **Название:** `mts-credit`

### Запуск проекта

Находясь в директории проекта, последовательно выполни следующие команды:

```bash
mvn clean package -DskipTests
java -jar target/Credit-Service-0.0.1-SNAPSHOT.jar
```

---

## Запуск с помощью Docker

Если установлен **Docker**, проект можно развернуть в контейнерах без локальной установки PostgreSQL, Java и Maven.

Находясь в директории проекта, выполни:

```bash
docker compose up --build
```
